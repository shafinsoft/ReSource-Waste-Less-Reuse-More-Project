# ReSource – Waste Less, Reuse More 🌱

**ReSource** is a web-based marketplace designed to connect suppliers of surplus and reusable materials with buyers who need them. The platform encourages material reuse, reduces waste, and promotes a sustainable environment by making it easier to discover, request, exchange, and manage reusable resources.

The platform provides three separate user modules: **Buyer, Supplier, and Admin**, each with dedicated interfaces and dashboard functionalities.

---

## 🌍 Project Overview

Many reusable and surplus materials are discarded even when they can be useful to others. ReSource aims to reduce this problem by creating a digital marketplace where suppliers can list available materials and buyers can search for materials, submit requests, compare quotations, and manage orders.

The platform focuses on:

- Promoting material reuse and sustainability.
- Connecting buyers with material suppliers.
- Simplifying material listing and discovery.
- Managing material requests and quotations.
- Tracking orders and exchanges.
- Providing centralized platform administration.

## 🔄 How ReSource Works

The platform follows a simple marketplace workflow.

**Step 1 – Browse Materials**

Buyers explore available reusable and surplus materials.

**Step 2 – Post a Request**

Buyers submit requests describing the materials and quantities they need.

**Step 3 – Get Quotations**

Suppliers review buyer requests and provide quotations.

**Step 4 – Compare Offers**

Buyers review and compare received quotations.

**Step 5 – Make an Order**

Buyers proceed with suitable supplier offers.

**Step 6 – Manage Exchanges**

Buyers and suppliers track their orders and exchange activities.

## 🚀 Installation and Setup

### Prerequisites

- Windows, macOS, or Linux
- Visual Studio Code
- Google Chrome or another modern browser
- Git
- Live Server Extension (recommended)

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the Project

Open the downloaded project folder in Visual Studio Code.

### Step 3: Install Live Server

1. Open Visual Studio Code.
2. Navigate to Extensions.
3. Search for Live Server.
4. Install the extension.

### Step 4: Run the Project

1. Locate `index.html`.
2. Right-click the file.
3. Select Open with Live Server.
4. The ReSource homepage will open in your browser.

**Alternative:** Open `index.html` directly in a modern web browser.
